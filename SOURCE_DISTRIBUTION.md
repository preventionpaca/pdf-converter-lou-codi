# Publication du code source

PDF Converter – Lou Còdi est distribué sous licence AGPL-3.0-or-later.

## Pour chaque version publique

1. Créer un tag Git signé correspondant exactement au numéro affiché par l’application.
2. Publier le code source complet de ce tag sur le dépôt public Lou Còdi.
3. Publier le fichier de verrouillage des dépendances et les scripts ayant produit les
   installateurs Linux, Windows et macOS.
4. Joindre `LICENSE`, `THIRD_PARTY_NOTICES.md` et les licences collectées dans chaque
   paquet binaire.
5. Ajouter dans la page de téléchargement et dans l’application un lien direct vers le
   tag source correspondant à l’installateur.
6. Conserver le code source accessible aussi longtemps que les binaires sont distribués,
   conformément aux modalités retenues dans l’AGPL.

## Contributions de soutien

Le logiciel et toutes ses fonctions restent accessibles gratuitement. Une contribution
à Lou Còdi peut supprimer les rappels de soutien sur l’appareil, mais ne modifie pas les
libertés accordées par l’AGPL et n’interdit pas l’étude, la modification ou la
redistribution du programme.
